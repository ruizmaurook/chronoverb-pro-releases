# chronoverb-pro-releases
Chronoverb Pro: CLAP delay + convolution reverb for Windows and Linux. Binary releases only.

- **Windows 10/11 (64-bit):** `ChronoverbPro_v1.0.0-beta.1.zip` (release `pro-v1.0.0-beta.1`).
- **Linux (64-bit, X11 / XWayland):** `ChronoverbPro_v1.0.0-beta.2_linux.zip` (release `pro-v1.0.0-beta.2`). Not verified in a DAW yet.

Each zip contains the plugin, the manual (English and Spanish, with install steps for both systems), the changelog and the third-party licences.
